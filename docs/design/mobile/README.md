# Fool's Gold Club — mobile design reference

Unzip this folder into `docs/design/` in the makeMoney repo, so it becomes `docs/design/mobile/`. Then paste `PROMPT.md` into your Claude session.

- `screens/` holds 22 screenshots of every screen and state at 393 × 852 (exported at 2×). They show layout, content and behaviour. Their colours come from the design canvas, not your app; the prompt tells Claude to keep your app's current colours.
- `source/` holds the design's source files, one per screen. Open them as text for exact sizes, spacing, copy and interactions. They need the design canvas's runtime to render, so use the screenshots to see them.
- `PROMPT.md` is the prompt.

Screens: 01–03 Home, 04–05 Live, 06–09 Match page (Popular, markets, Bet Builder, Stats), 10–13 Bet slip (Multiple, Singles, placing, bet placed), 14–17 My Bets (open, cash-out confirm, cashed out, settled), 18–19 Casino, 20–21 Account (with Set limits open), 22 Loading.
